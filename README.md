# 📝 TaskBuddy

## Smart Task Management Application

> A clean, responsive and user-friendly task management application built with React and Vite.

---

## 🚀 About The Project

**TaskBuddy** is a modern task management web application designed to help users organize, prioritize and track their daily tasks efficiently.

The application allows users to create tasks, assign priorities and categories, mark tasks as completed, monitor their progress, and delete tasks when they are no longer required.

The main goal of TaskBuddy is to make everyday task management simple, organized and easy to use.

---

## ✨ Features

- ➕ Add new tasks
- ⚡ Set task priority: Low, Medium and High
- 🏷️ Organize tasks by category
- 📚 Categories: General, College, Work and Personal
- ✅ Mark tasks as completed
- 📊 Automatic progress calculation
- 📈 Dynamic progress bar
- 🗑️ Delete individual tasks
- 🧹 Clear all tasks
- ⌨️ Add tasks using the Enter key
- 📱 Responsive design
- 🎨 Clean and modern user interface

2.Enter your task in the input field.
3.Select the required priority.
4.Select the appropriate category.
5.Click Add Task.


•Complete a Task

Click the checkbox beside a task.

The task will be marked as completed and the progress percentage will automatically update.


•Delete a Task

Click the Delete button associated with the task.

Clear All Tasks

Click Clear All to remove all currently listed tasks.
